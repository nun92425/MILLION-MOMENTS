使い方

  1. メイン画像を選ぶ: 完成させたい絵を1枚選びます。明暗がはっきりした画像が向いています。
  2. 素材画像を選ぶ: 配信サムネやスクショなど、モザイクの粒になる画像を大量に選びます。フォルダごとドラッグ&ドロップできます。
  3. タイル数を調整: 細かいほど綺麗ですが重くなります。素材が1000枚なら80-100、500枚なら60-80が目安。
  4. 生成: ボタンを押すとブラウザ内で自動計算。数千マスでも1-2分程度。
  5. 保存・共有: PNGで保存し、Xなどでファンアートとして投稿。超高解像度の原寸配布は避け、全体像+拡大切り抜きの投稿がおすすめです。

MILLION MOMENTS について

「無数の瞬間が、一つの景色になる。」
一つ一つの配信、一つの動画、一つの思い出。小さな瞬間が集まり、今の景色を作っている。
本ツールはその考えを、フォトモザイクの構造そのもので表現するために作られました。
詳細は 企画書 をご覧ください。

本サイトはサーバーに画像を送信しません。数百〜数千枚の画像処理もブラウザ内で完結し、RenderのStatic Siteとして無料で運用されています。

MILLION MOMENTS — 非公式ファンメイドツール | Built with Vite + Canvas API | 画像はブラウザ内でのみ処理されます

素材の利用条件は各権利者のガイドラインに従ってください。本ツール自体はMITライセンスで公開予定
